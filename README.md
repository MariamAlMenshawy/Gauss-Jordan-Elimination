# Gauss–Jordan Elimination 

A simple web-page that solves systems of linear equations using the Gauss–Jordan elimination method:
- The program takes an augmented matrix as input.
- It performs row operations (swap, multiply, add) to convert the matrix into Reduced Row Echelon Form (RREF).
- Finally, it displays each step clearly and shows the final solution, or indicates if the system has no solution / infinite solutions.

## How to Run
- Open the project folder.
- Run the file LinearAlgebraProject.html in any web browser.
- Enter the matrix size (number of equations and variables).
- Fill in the augmented matrix values.
- Press Solve to get the steps and the final RREF matrix.
